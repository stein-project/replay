# Replay 0.1.1: open source

Replay is now open source, under the Mozilla Public License 2.0, at github.com/Stein-Project/replay.

- **Open source**: anyone can read the code, report a bug pointing at the exact line and contribute.
- **Built with the Stein SDK**: the same tools any mod author uses. Nothing changes in how it works, and your settings stay where they are.
- **Requires Stein Loader 0.1.24** (the 0.1.30 installer): the Loader now links what Replay reads from the game.
