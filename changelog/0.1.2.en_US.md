# Replay 0.1.2: dying no longer slows the game

Dying no longer changes how fast the game runs, and servers that do not allow the death replay during the match are respected.

- **The game keeps its pace on death**: the death replay used to slow the game's clock, which also put your game out of step with the server for a moment. It no longer touches it.
- **Replay after the match where a server forbids it**: on a server that does not allow it, the death replay is not shown while you play there. It is still recorded and saved, so you can watch it later.
- **Needs Stein Loader 0.1.28**, which comes with the pack 0.1.36.
