# Replay 0.1.3: lighter in big fights

A maintenance version: recording costs less in crowded places, so the game keeps steadier frames.

- **Less work every tick**: each tick the recorder skips the players and mobs that are too far away before anything else. What it records does not change.
- **Needs Stein Loader 0.1.28**, which comes with the pack 0.1.36.
